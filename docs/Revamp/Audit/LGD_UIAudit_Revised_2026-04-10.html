WindowInsets + edge-to-edge on all scaffolds — GAP-05
Sprint 1 · Priority 3

Android 15 forces edge-to-edge by default. Without this, content hides under the status bar and nav bar on modern devices.

// MainActivity.kt + all Scaffold-containing composables MainActivity.kt — In onCreate(), before setContent: WindowCompat.setDecorFitsSystemWindows(window, false) Every Scaffold in app-owned screens (SettingsScreen, PersonalExpenseTrackerScreen, TodoTasksScreen, AppTourOverlay, inline settlement): Scaffold( modifier = Modifier.windowInsetsPadding(WindowInsets.systemBars), topBar = { ... }, ... ) For screens with a CenterAlignedTopAppBar: CenterAlignedTopAppBar( windowInsets = WindowInsets.statusBars, // ensures correct top padding ... ) For ModalBottomSheet (AddExpenseDialog): ModalBottomSheet( windowInsets = WindowInsets.navigationBars, ... ) Status bar colour (in LgdTheme or MainActivity): val systemUiController = rememberSystemUiController() SideEffect { systemUiController.setStatusBarColor( color = if (darkTheme) Color(0xFF1C2333) else Color(0xFF0D7A6E), darkIcons = !darkTheme ) }
