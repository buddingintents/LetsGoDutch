Critical Gaps to Fix Now
These are the issues that most visibly undermine the Fresh Mint direction regardless of anything else being done. Fix these first before adding new features.
🔴 Critical

BalanceSummaryCard missing from GroupsScreen

The top-level "You are owed ₹X / You owe ₹X" gradient card is the single most impactful screen element in the spec. Its absence makes the Groups screen feel like a bare list with no financial context. Users open the app to check their balance — give it to them immediately.

Fix: Add aggregate balance computation to GroupsViewModel, build the card composable.
🔴 Critical

InsightsTab still shows placeholder charts

The Insights tab is one of the two tabs in the group detail screen. If it shows generic grey bar-placeholder boxes, every user who taps it gets a broken experience. A charting library (Vico is Compose-native) must be added and wired to the existing balance/expense data.

Fix: Add `co.yml.vico:vico-compose:1.x` to feature:ledger. Build PieChart + BarChart composables.
🔴 Critical

Hardcoded colors bypassing the theme

Vibe-coded rewrites frequently emit Color(0xFF1C2333) literals in composables rather than MaterialTheme.colorScheme.surface. This means dark mode either looks wrong or is accidentally correct for one screen and broken on the next. Audit every screen file for hex literals.

Fix: grep for "Color(0x" in all feature modules. Replace with MaterialTheme.colorScheme references.
🟡 Important

GradientButton not used consistently

If the GradientButton composable exists in core:designsystem but screens still call standard FilledButton for primary CTAs, the brand gradient disappears from the most prominent interactive elements. The "Add Expense" and "Save Changes" buttons should always use GradientButton.

Fix: Search for "FilledButton" / "Button(" in all feature modules and replace primary CTAs.
🟡 Important

WindowInsets missing — content behind status bar

On Android 15 / edge-to-edge API the default behaviour puts content under the system bars. Without Modifier.windowInsetsPadding(WindowInsets.statusBars) at the scaffold level, top-app-bars overlap the status bar, making every screen look sloppy on modern devices.

Fix: In LgdTheme or MainActivity: WindowCompat.setDecorFitsSystemWindows(window, false). Add insets to each Scaffold's topBar.
🟡 Important

AppTour progress dots still asterisks

The animated pill-style progress indicator (inactive=8dp wide, active=20dp wide, animateDpAsState) is the most distinctive UI detail in the tour and the most commonly skipped. If the tour still shows "* o o o o" it signals the whole tour was left un-revised.

Fix: Replace TourDots composable with animated pill Row. ~20 lines of Compose.
🟡 Important

Settings screen doesn't show canonical Account ID

Per the identity plan (section 8), the user's stable Account ID (userId.take(8).uppercase()) should be visible in Settings. This is both a trust signal and a debugging tool for invite/identity issues. Currently missing because the identity plan was separate from the UI plan.

Fix: Add "Account ID" row to ProfileCard in SettingsScreen showing userId.take(8).uppercase() in DM Mono font.
🔵 Polish

Sora font falls back to system font on first cold launch

GoogleFont provider downloads the font asynchronously. On first launch users see the system font for ~500ms before Sora loads. Fix by providing fallback fonts in the FontFamily definition or bundling Sora as a resource font in res/font/.

Fix: Add fonts/sora_*.ttf to res/font. Use FontFamily(Font(R.font.sora_bold, weight=FontWeight.Bold), ...) as primary, keep GoogleFont as fallback.
🔵 Polish

README still describes v1 "Google-only" auth

The README says "Auth: Google Sign-In mandatory for all members" but anonymous auth is now implemented. This will confuse contributors and Codex agents. Update the README to reflect Phase 4 (identity upgrade) and the anonymous auth flow.

Fix: Update README auth section; add anonymous → Google upgrade path description.
🔵 Polish

SettlementScreen payment rows lack personality

"Raj pays Priya ₹420" should use the Avatar→Arrow→Avatar layout specified. It currently almost certainly renders as a plain text list. This is the screen users share / screenshot, so it needs to look polished — it's your viral marketing surface.

Fix: Build PaymentRow composable. InitialsAvatar + directional arrow icon + amount + recipient InitialsAvatar.
